# Rakjai

Landing page for Rakjai, a mobile application for discovering and
tracking BL & GL series.

## Status

🚧 Currently in development.

## About

Rakjai allows users to:

- Discover BL & GL series
- Track watched episodes
- Explore upcoming series
- Follow episode release dates
- Discover new content

## Technologies

- HTML
- CSS
- Vercel

## Project

This repository contains the public landing page for Rakjai.

The Rakjai mobile application is currently under development.
